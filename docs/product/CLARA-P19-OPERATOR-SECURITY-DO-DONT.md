# CLARA P19 Operator Security Do/Don't

Operator security do/don't guide exists.

Do:

- Use provider auth for internal team usage.
- Confirm real workspace membership before using CLARA for real work.
- Keep notes concise and business-relevant.
- Report suspicious auth/workspace behavior.

Don't:

- Do not use mock/demo mode for real internal CRM work.
- Do not paste secrets, tokens, auth headers, raw provider payloads, raw prompts, raw DOM, raw HTML, or payment data into CLARA or issue reports.
- Do not treat client-supplied workspaceId as authority.
- Do not bypass viewer read-only behavior.
- Do not activate billing/payment, official WA/IG/TikTok APIs, public SaaS launch, public GA launch, or outbound auto-send.
